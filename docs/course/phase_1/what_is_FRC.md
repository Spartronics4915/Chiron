## What is FRC?

FRC stands for First Robotics Competition. FRC is a highschool robotics competition that starts with a game release in early January, and runs all the way to the World Championship in late April/early May. For more info, check out the [FRC Website] (https://www.firstinspires.org/programs/frc/)
