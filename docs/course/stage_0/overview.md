title: Stage 0 - Overview
---

Learning **Python** is the most important step in learning FRC programming. Using **Python**, we can write code that allows a robot to run a motor, adjust speed, and much more. While there is a lot to learn when learning **Python**, Stage 0 will only cover the basics.

Each page in **Stage 0** will cover a different essential topic. If you’re new to programming, go through each step in order.

This stage will cover the following topics:

- Python Fundamentals
- Operators
- Conditionals
- Loops
- Classes and Objects
- Methods and Mutable State
- Arrays and For-Each Loops
- Interfaces, Generics, and Lists
