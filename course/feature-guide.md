The sidebar is the course's table of contents. Follow it from top to bottom
the first time through; later, search is useful when you want to revisit a topic.
On a narrow screen, open the navigation menu to find the sidebar. The outline
on each page links to its headings.

## Code examples

This is a **code block**. It preserves indentation, which matters in Python:

```python
print("Hello, Spartronics!")
```

The block itself doesn't run anything. We'll explain where to put it in the first
Python lesson. A copy button copies the code, not the surrounding explanation.
Commands labeled `sh` or `powershell` belong in a terminal, not inside a `.py` file.

## Notebooks

One later lesson uses a **Jupyter notebook** to make the order of program execution
visible. A notebook contains text and separately runnable blocks called cells.
You can read its saved outputs without running anything. For work you want to
keep, download a copy into `student-work` and use VS Code. You will learn the exact
steps before you need them. Ordinary lessons use normal Python files.
