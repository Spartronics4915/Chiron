title: Stage 0 - Python Fundamentals
---

Python lets us describe the decisions a robot should make, but it also lets us
learn those ideas without a robot at all. We will start with text printed in a
terminal and gradually build a model of an intake that remembers whether it has
a game piece.

Work through these lessons in order. Each introduces ideas used by the next, so
skipping a word you don't recognize can make a later example feel much harder.
You don't need to be fast; take time to predict and explain what happens.

```{toc}
:context: children
```

Most exercises belong in `student-work/foundations`. The initial files are already
there from setup. When a lesson asks for a new file, use Explorer's **New File**
action inside that folder and type the full filename, including `.py`.

At the end you'll build a small intake model across two files and check its
decisions. Stage 1 will connect those same ideas to the robot framework.

:::{note}
If you need more support learning python throughout this learning course, try https://www.w3schools.com/python/, or if you prefer videos: https://www.youtube.com/watch?v=rfscVS0vtbw. 
:::
